🐧 Linux

⚙️ System Configuration

Inspect your machine, manage services, and configure things like hostname, time and environment variables. Most changes here need sudo.

Beginner tips
  • System-wide config files live in /etc.
  • Your personal shell config is ~/.bashrc (or ~/.zshrc). Reload with source ~/.bashrc.
  • Logs live in /var/log or are viewed with journalctl.

uname

beginner

Show kernel and OS information.

bash
uname -a

cat /etc/os-release

beginner

Show which Linux distribution and version you're running.

bash
cat /etc/os-release

hostnamectl

intermediate

View or set the machine's hostname.

bash
hostnamectl
sudo hostnamectl set-hostname my-server

timedatectl

intermediate

View or set date, time and timezone.

bash
timedatectl
sudo timedatectl set-timezone Europe/Berlin

systemctl

intermediate

Start, stop, restart, enable and check services (systemd).

bash
systemctl status nginx
sudo systemctl restart nginx
sudo systemctl enable --now ssh

journalctl

intermediate

Read system and service logs.

bash
journalctl -u nginx --since today
journalctl -f

export

intermediate

Set an environment variable for the current session. Add to ~/.bashrc to make it permanent.

bash
export EDITOR=nano
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc

env / printenv

beginner

List environment variables.

bash
printenv PATH

alias

beginner

Create a shortcut for a long command.

bash
alias ll='ls -lah'
alias gs='git status'

crontab

intermediate

Schedule commands to run automatically. Format: min hour day month weekday command.

bash
crontab -e
# every day at 2:30
30 2 * * * /home/alex/backup.sh

uptime

beginner

How long the system has been running and the load average.

bash
uptime

free

beginner

Show memory (RAM) usage.

bash
free -h

lscpu / lsblk / lsusb

beginner

List CPU details, block devices (disks) and USB devices.

bash
lscpu
lsblk
lsusb

reboot / shutdown

⚠ careful beginner

Restart or power off the machine.

bash
sudo reboot
sudo shutdown -h now
sudo shutdown -r +10

Tip: press Ctrl K or / to search from anywhere. Commands marked ⚠ careful can delete data or change your system — double-check before running.
